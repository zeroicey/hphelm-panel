# 设计系统：无卡片 · 紧凑 · Catppuccin Mocha

> 改 UI 先读这份。核心原则只有三句：**不用卡片**、**标题不占行**、**坐标只写在 `theme.h`**。
> 相关：[`architecture.md`](architecture.md)（渲染机制）· [`verify.md`](verify.md)（怎么量）

---

## 一、三条硬原则

### 1. 不用卡片

**没有圆角框、没有底色块。** 分区只靠三样东西：

| 手段 | 怎么用 |
| --- | --- |
| **1px 细线**（`v_rule()`） | 只在「带与带之间」画，全宽；颜色 `C_SURFACE1 @ 0.45` |
| **字号层级** | 标题 11pt / 值 9~10pt / 大数值 26pt / 进程行 14pt |
| **留白** | 栏间 26 逻辑像素、带间 12 逻辑像素 |

原先的 `v_panel_box()`（圆角框 + `C_MANTLE@62%` 填充）**已删除**，不要加回来。

### 2. 紧凑：标题不单独占行

区块标题（如「CPU」「内存」「网络」）与它的右侧数值（如 `57.6°C`）**在同一行**，左标题右数值。
顶栏只有一行。系统三栏并排而不是上下堆。

### 3. 坐标只写在 `theme.h`

任何 `view_*.c` 里出现 `L_xxx` 常量以外的布局数字（除了栅格内相对偏移）都算坏味道。
绘制全程在**逻辑像素**下进行，主循环统一 `cairo_scale(SCALE)`；`SCALE` = 物理/逻辑（本机 1.48）。

## 二、版式常量（`src/theme.h`）

本机：1920×1080 物理 / 141.8 DPI ⇒ `SCALE=1.48` ⇒ **逻辑屏 ≈1297×729**。

### 三列结构（2026-10-21 起）

```
┌ 顶栏（一行）─────────────────────────────────────────────────────────────┐
│ hphelm 本地   hpcore 生产 ● │            2026-10-21 17:04:53 ● 24×7     │
├────────────────────┬────────────────────┬────────────────────────────────┤
│ 本机 hphelm  本地   │ 生产 hpcore 在线   │ 进程榜  本机  共 258          │
│ 生产 192.168.5.50  │ 生产 …102         │ 1 codex    430M   1234        │
│ CPU 58.2°C         │ CPU 42.9°C        │ …12 行                        │
│ 13% schedutil      │ 31% powersave     │ ───────── 分隔线 ─────────    │
│ [CPU 条] 每核柱     │ [CPU 条] 每核柱    │ 生产进程  共 429              │
│ [CPU 5min 曲线]    │ [CPU 5min 曲线]   │ 1 magpie   211M   1572        │
│ 内存 / [条] / 曲线  │ 内存 / [条] / 曲线 │ …12 行                        │
│ 网络 / [双曲线]     │ 网络 / [双曲线]    │                               │
│ 磁盘 / [条] / 容器  │ 磁盘 / [条] / 容器 │                               │
└────────────────────┴────────────────────┴────────────────────────────────┘
```

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `L_MARGIN` | 18 | 页面外边距 |
| `L_COL_GAP` | 26 | 列间距（竖细线画在它的中点） |
| `L_TOP_Y` / `L_RULE1_Y` | 12 / 46 | 顶栏文字 / 顶栏下细线 |
| `L_HOST_FRAC` | 0.348 | **每台主机列**的宽度占比（≈452 逻辑像素） |
| `L_PROC_ROWS` | 12 | 进程榜每段行数（本机 12 + 生产 12） |
| `L_PROC_SEC_H` / `L_PROC_SEC_GAP` | 316 / 16 | 每段高度 / 两段之间的空隙 |
| `L_PROC_ROW_H` | 24 | 进程榜行高 |

**进程榜宽度是算出来的**（`mw - 2*host_w - 2*COL_GAP`），不写常量 ——
`const double w[3] = {a, b, 0}` 那种「宽度写 0」的错版不会报错，只会画出一根线（我们踩过）。

### 主机列内部（两台共用同一套常量）

| 常量 | 值 | 行 |
| --- | --- | --- |
| `L_H_NAME_Y` | 58 | 主机名 + 右侧连接状态（本地/在线/离线 Ns） |
| `L_H_ROLE_Y` | 82 | 角色 · IP · up 时长 · 核数 |
| `L_H_CPU_Y` / `L_H_BIG_Y` | 104 / 126 | CPU 标题 + 温度 / 26pt 大百分比 |
| `L_H_CPU_BAR` / `L_H_CORES_Y` / `L_H_CORES_H` | 166 / 184 / 50 | CPU 条 / 每核柱（>16 核自动两行） |
| `L_H_CPU_SPARK` | 262 | CPU 5 分钟曲线 |
| `L_H_MEM_Y` / `L_H_MEM_SPARK` | 318 / 428 | 内存（标题·大百分比·条·swap）/ 内存曲线 |
| `L_H_NET_Y` / `L_H_NET_SPARK` | 484 / 554 | 网络（↓↑ 速率）/ 双曲线 |
| `L_H_DISK_Y` / `L_H_DISK_BAR` | 610 / 634 | 磁盘标题 / 磁盘条（下面一行容器数·SSD） |
| `L_H_SPARK_H` / `L_H_LBL_GAP` | 46 / 16 | 曲线高度 / 「5 分钟」标签在曲线上方多少 |

**改版式的铁律**：这些是**绝对逻辑像素**，不是相对 `L_BODY_Y` 的偏移。
（本轮我按「相对」写了第一版，结果 CPU 标题跑到主机名上面、整列下移 100px —— 编译零告警，
只有量像素才看得出来。）

**进程榜列内行格式**：`名次(9pt 暗) · 进程名(14pt) · pid(9pt 暗) · 内存(14pt 右对齐到列右边界)`。
名称按「列宽 - 内存宽 - pid 预算」截断成 `前缀…`，**截断点会退回 UTF-8 字符边界**
（切一半多字节字符 pango 会画豆腐块，是静默错误）。字体等宽 ⇒ 用 `v_char_w()` 一次测量按字符数估算，
**不做逐字符测量**（那会让单帧绘制时间翻倍）。

## 三、配色（Catppuccin Mocha）

底色：`v_bg()` 竖向渐变 `#0b121d → #020306`（面板与登录页**共用**，保证两个界面风格统一）。

| 语义 | 颜色 | 用在哪 |
| --- | --- | --- |
| 主色 / CPU | `C_MAUVE` `#cba6f7` | CPU 标题、CPU 条与曲线、登录页强调 |
| 内存 | `C_BLUE` `#89b4fa` | 内存标题/条/曲线 |
| 网络下行 | `C_TEAL` `#94e2d5` | ↓ 速率与曲线 |
| 网络上行 | `C_PEACH` `#fab387` | ↑ 速率与曲线 |
| 正常 / 网络标题 | `C_GREEN` `#a6e3a1` | 网络标题、tailscale 在线、`24×7` 点 |
| 进程榜 | `C_YELLOW` `#f9e2af` | 进程榜标题、认证中 |
| 危险 | `C_RED` `#f38ba8` | 温度 ≥85、CPU 核 ≥80%、磁盘 ≥90%、错误信息 |
| 正文 | `C_TEXT` `#cdd6f4` | 主要数值 |
| 次要 | `C_SUBTEXT0/1`、`C_OVERLAY0/1` | 标签、单位、暗注 |

温度语义：`<70` teal 正常 → `70~85` peach → `≥85` red（`v_temp_color()`）。

## 四、曲线（sparkline）规范

```c
void v_spark (cr, x, y, w, h, ring, col, vmax);              // 单曲线
void v_spark2(cr, x, y, w, h, r1, c1, r2, c2, vmax);         // 双曲线共用同一量程
double v_nice_ceil(double v);                                 // 量程吸附 1/2/5×10ⁿ
```

四条规矩：

1. **量程必须稳定**：用 `v_nice_ceil()` 吸附到 1/2/5×10ⁿ。
   否则「历史最大值」一变，整条曲线就整体跳一下（用户会看成「在抖」）。
   CPU / 内存传固定 `100.0`。
2. **不预填**。⛔ 不要用「当前值」把环形缓冲填满来治「起步为空」：
   那个值来自启动瞬间的 120ms 窗口，实测常是 **0**、偶尔是**突发尖峰** ⇒
   曲线要么贴底、要么被假尖峰把量程顶上去把真数据压扁。**这是伪造历史。**
3. **空态用零基线**：`spark_base()` 在底部画一条 `C_SURFACE1@30%` 的线 ⇒
   看起来是「0 值」而不是「坏了」；曲线本身从右侧诚实生长（跟 htop 一样）。
   真要「一开机就铺满」，正解是**缩短窗口**（只画最近 N 个样本）。
4. **双曲线共用量程**：上下行放一起比较才有意义（`v_spark2` 自动取两者最大值再 nice 化）。

窗口：`RING_CAP = 300` 点 @ 1 Hz = **5 分钟**。

## 五、进度条与每核柱

- `v_bar()`：自带轨道（`C_SURFACE0@85%`），高度 10~12 逻辑像素，圆角 = 高/2。
  CPU 用 mauve、内存用 blue、磁盘用 teal（≥90% 转 red）。
- `v_core_bars()`：
  - **带轨道**（否则空闲时柱高 1px，根本看不见 —— 用户原话之一）；
  - **最低 2px 亮条** ⇒ 空闲核也能看出「这里有核、现在是 0%」；
  - 颜色随负载：`>80%` red / `>50%` peach / 其余 blue；
  - `>16` 核自动分两行。

## 六、登录页

与面板**同一套无卡片风格**：整屏渐变底 + 居中的「时钟 / 日期 / 主机信息 / 细线 / 用户名 / 密码框」。

- **没有外层卡片**（原来那个 `C_MANTLE` 圆角框已删）。
- 唯一保留的「框」是**密码输入框本身** —— 它是输入控件，不是装饰性卡片。
- 认证中（`busy`）：一行「正在验证…」+ **不确定态进度条**（相位取自 `m->now`）。
- 出错：红字 + 「N 秒后可重试」。
- 光标：2Hz 闪烁（主循环里 `(int)(now_s()*2) % 2`）。

## 六·五、性能：一帧 5~10ms 花在哪（2026-10-21 实测）

面板 1 Hz 重绘，**单帧绘制时间 × 1 Hz ≈ CPU 占用**（这台机上 10ms/帧 ≈ 1% of one core）。
所以改 UI 时顺手看一眼 `HPHELM_PANEL_DEBUG=1` 的「绘制 Xms」。三个已知大头：

| 大头 | 现象 | 已做的处理 |
| --- | --- | --- |
| **pango 整形次数** | 一帧 100+ 次（两台主机 + 24 行进程） | 右对齐/居中**复用同一次排版**取宽度（`v_text_right_w`）；进程名按字符宽估算截断 |
| **整屏渐变填充** | 每帧 4~5ms（cairo pattern 在 Xlib 表面上掉进客户端渲染） | 渐变只渲染进一张 `bgpix`，每帧用一次 `XCopyArea` 复制过来 |
| **进程榜逐字符测量** | 每删一个字符量一次宽度 ⇒ 每帧几百次整形 | 等宽字体 ⇒ `v_char_w()` 量一次「MMMMMMMMMM」除 10 |

⚠️ **量 CPU 前先看 load average**。本轮我在 `load average: 22.99`（无关的 go 编译）时量了几轮，
数字全部作废 —— 量到的是别人的负载，不是面板的。判据必须写清「同一时刻的 load」才有可比性。

## 七、改版式的检查清单

改完必须量（见 [`verify.md`](verify.md)）：

- [ ] 整屏 ASCII 里没有「空栏」「叠字」「越界」
- [ ] 每核柱：根数 = 核数，宽度/间距与常量算出来的一致
- [ ] 进程榜：**两段各 12 行**（本机 + 生产），行距 24 逻辑像素，内存右边界对齐到列右边界
- [ ] 两台主机列的纵向锚点**逐条对齐**（同名行在同一 y）—— 用一个 `draw_host()` 就是为了这个
- [ ] 曲线有零基线，且没有贴到下一根细线上
- [ ] 登录页无卡片、输入框居中、认证中进度条在动
- [ ] 顶栏时间精度到秒（证明面板 1 Hz 在跑）

⚠️ **`const double w[3] = {a, b, 0}` 这种「宽度写 0」不会报错**，只会画出一根线或什么都不画
（踩过：网络栏宽度 0 ⇒ sparkline 压成竖线、右对齐文字挤到左边缘，编译零告警）。
